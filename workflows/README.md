# ComfyUI reference GUI schema 0.4 (external worker)

The JSON here is the original Photo400 2.5 **reference blueprint**, migrated into Aether with its original connections. It contains 51 nodes, 73 links and 24 groups.

**IMPORTANT:** This is not a complete native Samsung S24 Ultra process and not a one-click 400 MP GPU render. Only one sample neural tile lane is active. The 400 MP CPU-side BigTIFF renderer and the inter-stage scheduler are separate processes. ComfyUI requires a real remote GPU worker plus installed compatible custom nodes and checkpoints; no worker is currently validated.

Some third-party nodes and their specific input contracts may change. The JSON has passed static ID/link checks; it has not passed runtime import/inference on a ComfyUI server.

Opt-in network processing is subject to user consent, encryption and privacy requirements. Synthetic content is not forensic restoration.
